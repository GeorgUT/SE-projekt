# Deltamap

Deltamap on Tartu Ülikooli Delta õppehoone veebipõhine kaart.
Rakendus aitab leida ruume ja õppejõudude kabinette ning kuvab
teekonna alguspunktist soovitud sihtkohta.

## Veebileht

https://kodu.ut.ee/~georghenry/SE-projekt/delta.html

## Võimalused

- Delta õppehoone nelja korruse kaartide vaatamine.
- Sihtkoha otsimine ruuminumbri, õppejõu nime või koha nime järgi.
- Alguspunkti ja sihtkoha vahelise teekonna kuvamine.
- Korruste vahetamine ja teekonna vaatamine korruste kaupa.
- Eestikeelne kasutusjuhend.
